# Chronicle 1.4.231

Released November 11, 2026.

Everything since 1.4.223.

## Changes

- **Quests the game only marks done:** an escort, or any quest with nothing to count, now gets its "ready to hand in" notification when you finish it.
- **No quest step goes unsaid:** if Chronicle ever misses one of the game's quest messages it holds back, it shows the game's own words as a notification instead.
- **Trades:** the game's yellow "Trade complete." message is hidden while Chronicle's own Trades notification shows.
- **Dungeon runs:** "My share of the loot" and the run's "Best loot" now appear only when you got something blue (rare) or better.
- **The Journey's class quests:**
  - Skyborne characters now see the other races' class quests from level 12 on, as they head into those races' lands. Where a quest comes in a version for each race, all of them show until you start one.
  - Several class quest chains that showed as separate chapters are now one chapter each: the paladin's Redemption, the charger and the Chillwind Point quests; the mage's wand from Tabetha; the warlock's Dreadsteed; and the Skyborne shaman's Call of Fire.
  - A few follow-up quests now appear only once the chapter before them is done, instead of all at once.

## Fixes

- Dungeon loot won on a roll is no longer listed as "Loot."
- The last boss's loot, rolled for after the run is marked cleared, now counts toward that run.

To report a bug, type `/chronicle bug` in game; for an idea, `/chronicle suggest`.
